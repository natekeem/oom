# IMAGE_PROMPTS.md

These prompts are for generating original OOM assets that evoke the familiar OPIc computer-test experience without requiring a screenshot asset.

## 1. EVA interviewer portrait

**Goal:** a neutral virtual interviewer used in the left-side exam panel.

Prompt:

> Professional virtual speaking-test interviewer portrait, Korean woman in her early 30s, calm friendly neutral expression, shoulder-length dark brown hair, simple light blue or cream business blouse, front-facing waist-up portrait, clean neutral office studio background, soft even lighting, realistic photography, centered composition, no text, no logos, no headset, no microphone, 4:3 portrait crop, high detail, trustworthy corporate assessment interface aesthetic.

Suggested output:
- 1024×1024 or 1024×1280
- Crop to 4:3 or 3:4 in CSS with `object-cover object-top`

## Important visual direction

Aim for these **feelings**:
- exam console rather than dashboard
- avatar + replay control as the visual anchor
- obvious recording state
- progress visible at a glance
- minimal distractions while speaking
- analysis tools only after the answer is finished

Avoid:
- glossy game UI
- analytics dashboard during speaking
- excessive gradients
- chat app look
- many colorful cards
- showing AI feedback while recording
