# Reference Code

이 코드는 repository에 그대로 덮어쓰는 완성 patch가 아니라 **구조를 명확히 전달하기 위한 reference**입니다.

실제 payload는 `../content/*.json`.

권장 통합:
1. types
2. levels
3. content data
4. storage
5. registry/selector
6. selection context/setup UI
7. STEP1~5 기존 imports를 resolved context로 교체

현재 저장소의 실제 Tailwind/theme/import convention을 우선 적용하세요.
