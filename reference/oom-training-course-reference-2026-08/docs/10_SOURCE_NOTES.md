https://www.actfl.org/assessments/postsecondary-assessments/oral-proficiency-interview-computer-opic

### ACTFL — Tips for OPI/OPIc Test Takers
https://www.actfl.org/assessments/postsecondary-assessments/opi/tips-for-opi-and-opic-test-takers

참고:
- spontaneous/unrehearsed speech를 평가.

## 난이도

다양한 공개 수험 자료는 낮은 IM 목표에 3~4, IH/AL 목표에 5~6을 선택하는 경향을 소개하지만 이는 공식 점수 보장 규칙이 아닙니다.

OOM v1은 교육 단계의 일관성과 기존 5-5 흐름을 위해:
- advanced = 5-5
- intermediate = 4-4
- foundation = 3-3

을 내부 preset으로 사용합니다.

## 2026-08-19 재점검 메모

- OPIc 공식 사이트는 Background Survey + Self Assessment를 기반으로 개인 맞춤형 시험을 제공하고, Function / Accuracy / Content-Context / Text Type을 평가한다고 설명한다.
- ACTFL OPIc와 test-taker tips는 spontaneous, unrehearsed speaking을 강조한다.
- 2026 공개 한국 준비 자료에서는 영화/공연/콘서트/공원/음악/걷기/조깅/국내·해외·집 휴가를 묶어 준비 범위를 줄이는 전략이 계속 확인된다.
- 따라서 Course 2를 준비 효율 추천으로 두고, Course 1과 Course 3는 관심사/스토리 다양성을 위한 선택 코스로 포지셔닝한다.
