## 1. 개선 우선순위 요약 (P0 / P1 / P2)

### P0 (보안, 핵심 안정성, 정책 무결성) — 상시 방어
- [x] **BYOK 세션 격리 및 위협 완화**: `sessionStorage` 기반 탭 세션 키 보관을 기본으로 하여 디스크 잔류 방지. 로컬스토리지 저장은 평문 저장임을 고지하여 공용 기기 주의 안내.
- [x] **음성 데이터 라이프사이클 관리**: 오디오 Blob을 브라우저 메모리에만 보관하고 세션 종료 시 즉시 해제. 커스텀 STT 사용 시 사용자 지정 엔드포인트로만 음성이 전달됨을 개인정보처리방침에 명시.
- [x] **과장 광고 및 보장성 표현 배제**: OPIc 공식 점수/합격 보장 금지 면책 고지 100% 준수.
- [x] **상태 의존 페이지 검색 색인 분리**: STEP 2~6 훈련 진행 뷰 17개 및 유틸리티 8개에 `noindex,follow` 부여 및 `sitemap.xml` 누출 방지.

### P1 (사용자 경험, 테스트 신뢰성, SEO/AdSense 인프라) — 금회 해결 및 준비

- [x] **매거진 30편 품질 및 출처 전수 검증**: ACTFL 및 OPIc 공식 규정 출처 100% 명시, 책임 저자 및 작성 근거 투명화.

- [x] **개인정보처리방침 네트워크 동작 일치**: 커스텀 STT 사용 시 음성 파일이 사용자 엔드포인트로 전송됨을 `legalPages.ts`에 명문화.

## 2. 금회 로컬 개선 내역 구분 (실제 코드 vs 문서)

### 2.1 실제 기능/테스트 코드 수정
- **대상 파일**: `src/TrainingCourse.test.tsx`
- **수정 사유**: Vitest 전체 테스트(53개 파일) 병렬 실행 시 시스템 부하로 인해 `findByText`의 기본 타임아웃(1000ms)을 간헐적으로 초과(1070ms)하던 flakiness 현상 제거.
- **수정 내용**: `TrainingSelectionGuard`를 테스트하는 17, 18, 19, 20, 21번 테스트 케이스의 `findByText` 쿼리에 `{ timeout: 4000 }` 옵션을 명시하여 환경 부하에 영향받지 않도록 견고화.
- **검증 결과**: `npm run test` 실행 결과 53개 테스트 파일 443개 테스트 전체 PASS (0 failed).

### 2.2 문서 및 정책 텍스트 수정
- **대상 파일**: `src/data/legalPages.ts`
- **수정 사유**: 커스텀 STT 사용 시 실제 브라우저에서 외부 엔드포인트로 음성 Blob 파일이 전송되는 네트워크 동작을 개인정보처리방침에 명확히 반영.
- **수정 내용**: `privacy` 섹션 1에 "사용자 지정 커스텀 STT(음성 인식)를 설정하여 사용하는 경우, 녹음된 음성 데이터는 브라우저에서 사용자가 설정한 외부 엔드포인트로 직접 전송되어 처리되며 오픽온미 서버로 전송되거나 보관되지 않습니다." 추가.

## 3. 사용자 검토 및 외부 확인이 필요한 사항 (Action Items)

다음 항목들은 로컬 코드 변경만으로 완료 처리할 수 없으며, 서비스 운영자의 외부 콘솔 확인 및 정책 결정이 필요합니다:

### 3.1 Google Search Console (GSC) 점검
- **확인 대상**: `https://search.google.com/search-console`
- **점검 항목**:
  1. **sitemap.xml 제출 상태**: `https://opic-on-me.com/sitemap.xml`이 정상 제출되었는지 확인.
  2. **페이지 색인 생성 보고서**:
     - "페이지 리디렉션 관련 제외": 트레일링 슬래시 통일 작업 이후 건수가 감소 추세인지 확인.
     - "크롤링됨 — 현재 색인이 생성되지 않음": 최근 갱신된 정적 HTML 본문이 크롤러에 의해 재수집되고 있는지 대표 URL(예: `/magazine/opic-survey-choice-guide/`, `/exam-guide/`)에 대해 'URL 검사' → '색인 생성 요청' 1~2회 수행 권장.

### 3.2 Google AdSense 콘솔 점검
- **확인 대상**: `https://adsense.google.com/`
- **점검 항목**:
  1. 사이트 검토 상태 및 과거 거절 상세 사유 확인.
  2. 현재 OOM은 6대 필수 신뢰 페이지 완비, 30편의 충실한 정보성 글, 인터랙티브 훈련 도구, 광고와 훈련 뷰의 엄격한 분리를 갖추고 있으므로 기술적 정책 적합성은 완비되었습니다.
  3. GSC에서 주요 URL들의 색인이 안정화된 시점에 "사이트 검토 요청"을 진행하는 것을 권장합니다 (승인은 심사팀의 고유 권한).

## 4. 비용 발생 가능 개선 사항 안내

현재 OOM은 **순수 정적 프런트엔드(GitHub Pages 무료 호스팅)**와 **Supabase 무료 티어(Google Auth + RLS profiles)** 기반으로 운영 비용이 \$0에 가깝습니다.
향후 다음 기능을 확장할 경우 추가 비용이 발생할 수 있습니다:

1. **관리형 AI (Managed Gemini API)**:
   - 현재는 사용자 BYOK 방식(비용 \$0)이 기본이며, 관리형 AI는 서버 기본 OFF 상태입니다.
   - 사용자 전원에게 관리형 AI 피드백을 무료 제공할 경우 Google Gemini API 종량제 비용이 발생할 수 있습니다.
2. **커스텀 도메인 및 호스팅**:
   - `opic-on-me.com` 도메인 갱신 비용 외에는 현재 정적 호스팅 비용이 발생하지 않습니다.
